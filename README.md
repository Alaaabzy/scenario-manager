# Управление сценариями текстовых приключений

Курсовой проект по дисциплине
«Разработка защищенных сетевых приложений».

Автор: Алзиуд Алаа
Группа: ИБ 2513

## Назначение

Приложение загружает текстовые приключения из внешних файлов.
Игрок выбирает действия и переходит между сценами.
Новые истории можно добавлять без изменения и перекомпиляции Java кода.

## Требования

Для запуска требуется Java 17 или новее.
Для сборки проекта требуется Maven.

## Сборка

В корневой папке проекта выполнить:

mvn clean package

Результат сборки:

target/scenario-manager-1.0-SNAPSHOT.jar

## Запуск

В Windows открыть файл run.bat.

Папка scenarios должна находиться рядом с run.bat.
Запускать приложение необходимо из корневой папки проекта.

## Управление

Введите номер действия и нажмите Enter.
В меню вариант 0 возвращает на предыдущий уровень.
В главном меню вариант 0 завершает приложение.

## Добавление истории

1. Создайте новую папку внутри scenarios.
2. Создайте в ней управляющий файл story.txt.
3. Добавьте текстовые файлы сцен в кодировке UTF-8.
4. Откройте список историй в приложении.

Перезапуск и повторная сборка приложения не требуются.

## Формат story.txt

[start]
text=start.txt
choice=Войти в замок|castle

[castle]
text=castle.txt

Название в квадратных скобках задаёт ID сцены.
Параметр text указывает файл с текстом сцены.
Параметр choice содержит текст действия и ID следующей сцены,
разделённые символом |.

Обязательна начальная сцена start.
ID сцен должны быть уникальными.
Все переходы должны вести к существующим сценам.
Сцена без вариантов выбора считается концовкой.

## Примеры историй

1. north: «Печать Севера».
2. island: «Остров туманов».

## Основные классы

Main: меню, пользовательский ввод и переходы между сценами.
Choice: вариант действия и ID следующей сцены.
Scene: ID, текст сцены и список действий.
StoryLoader: чтение и проверка файлов истории.
ScenarioCatalog: поиск доступных историй.
